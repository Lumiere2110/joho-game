# 今後の拡張アイデア

v0.1（最初の版）でできること：案件3つ（図書館・通販・クリニック）、6フェーズ、用語86語、ボットテスト。

## 追加したい分野・要素

- **案件を増やす**：自治体の防災情報（可用性・災害対策）、学校の成績管理（アクセス権）、工場のIoT（センサーデータ・時系列DB）、銀行（トランザクション・排他制御）、動画配信（CDN・帯域）、ゲームサーバー（リアルタイム通信）
- **データベース**：インデックスの選択、SQL を書くミニゲーム、トランザクションと排他制御（デッドロック）、NoSQL との使い分け
- **アルゴリズム**：探索・ソート以外（グラフの最短経路＝配送ルート、動的計画法、キャッシュの置換 LRU）
- **ネットワーク**：IPアドレス設計・サブネット、DNS、VPN、負荷分散方式
- **セキュリティ**：脆弱性診断・ペネトレーションテスト、インシデント対応の手順（初動・封じ込め・報告）、ゼロトラスト
- **運用**：監視アラートの設計、SLA と SLO、キャパシティプランニング、障害の振り返り（ポストモーテム）
- **マネジメント**：見積もり（ファンクションポイント）、ガントチャート・クリティカルパス、EVM、リスク管理
- **法務・契約**：著作権・ライセンス（OSS）、SLA 契約、下請法、電子帳簿保存法
- **データ活用**：運用データの分析で改善提案（KPI ダッシュボード）
- **ゲーム要素**：同時に複数の案件、社員の成長と性格、会社の設備投資、実績（アチーブメント）、難易度設定、知識チェックテスト
